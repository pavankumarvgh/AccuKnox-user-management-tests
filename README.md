# AccuKnox User Management Automation Tests

This repository contains **Playwright automation tests** for the **User login, Add, Edit,Search, Delete** in OrangeHRM demo.

## Features

- Full E2E flow: Login → Add User → Search User → Edit User → Validate → Delete User
- Each test scenario in a **separate test block**
- Proper waits and meaningful selectors
- HTML report for test results

1. Install Node.js (v16+ recommended)
